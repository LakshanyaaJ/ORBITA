# ORBITA Legacy Archives

This directory contains archived early prototypes and standalone tools that have been superseded or integrated into the active ORBITA application suite.

## Archived Projects

### 1. `archive/frontend-prototype/`
- **Description**: Early initial React prototype frontend created during early architecture phases.
- **Superseded by**: The unified production React application in `frontend/` (which includes real-time telemetry, camera control panel, phone IP camera streaming, procedure timeline, system diagnostics, and mission control).

### 2. `archive/orbita-mission-control/`
- **Description**: Standalone mission control dashboard originally built as an independent tool.
- **Status**: Completely merged and integrated into `frontend/src/mission-control/` with Google Apps menu switching and unified styling.
- **Reason for Archiving**: Preserved for reference and commit history without cluttering the active production application.
